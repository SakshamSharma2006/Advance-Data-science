# Advance Data Science

A collection of deep learning and data science notebooks covering neural network fundamentals, computer vision, audio classification, generative models, NLP/Transformers, time series forecasting, and a few applied projects. Built while exploring core concepts in advanced data science and deep learning.

## 📂 Repository Structure

### 🧠 Neural Network Fundamentals
- `Activation_Functions.ipynb` / `Activation_Function(use in dataset).ipynb` — Activation functions explained and applied to a dataset
- `Optimization_Techniques_for_deep_learning.ipynb` — Optimizers used in deep learning training
- `Regularization_(Deep_Learning).ipynb` / `Regularization_Techniques_in_Deep_Learning.ipynb` — Regularization methods (dropout, L1/L2, etc.) to reduce overfitting

### 🖼️ Computer Vision
- `MNIST_CNN_Classification.ipynb` — CNN-based digit classification on MNIST
- `CIFAR_10_MLP_Classification.ipynb` — MLP-based image classification on CIFAR-10
- `BrainMRI_Denoising AutoEncoder.ipynb` / `BrainMRI_DenoisingAE.ipynb` — Denoising autoencoder applied to brain MRI images
- `Yolo Simple Program.ipynb` — Basic object detection using YOLO

### 🎵 Audio Classification (GTZAN Dataset)
- `Saksham_ANN_MLP_(GTZAN_DataSet).ipynb` — ANN/MLP genre classification
- `CNN_(GTZAN)_Saksham.ipynb` — CNN genre classification
- `LSTM(GTZAN).ipynb` / `LSTM_+_RNN(GTZAN).ipynb` — LSTM and RNN-based genre classification
- `Sequencetial_Model(GTZAN).ipynb` — Sequential model for genre classification

### 🎨 Generative Models
- `GAN.ipynb` — Basic Generative Adversarial Network
- `GAN_with_LSUN.ipynb` — GAN trained on the LSUN dataset
- `GAN image and tet generation.ipynb` — GAN-based image and text generation
- `DCGAN_FashionMNIST.ipynb` — Deep Convolutional GAN on Fashion-MNIST
- `VAE for Learning Latent Architecture.ipynb` — Variational Autoencoder for latent space learning
- `Auto_Encoding_Saksham.ipynb` — Autoencoder fundamentals

### 📝 NLP & Transformers
- `BERT analysis.ipynb` — Analysis using BERT
- `Attention_Mechanism_Complete(Saksham).ipynb` — Attention mechanism from scratch
- `Transformers_english_to_hindi_Saksham_.ipynb` — English-to-Hindi translation using Transformers

### 📈 Time Series Forecasting
- `Chap 1 Fundamentals of Forecasting.ipynb` — Introduction to forecasting concepts
- `Chap 2 Understanding of time series.ipynb` — Time series components and analysis
- `Chap 3 Exponential Smoothing Methods.ipynb` — Exponential smoothing techniques

### 🔐 Applied Projects
- `ENCRYPTION - DECRYPTION.ipynb` — Encryption/decryption implementation
- `XGBoost(IPL).ipynb - Colab.pdf` — XGBoost model applied to IPL cricket data

## 🛠️ Tech Stack
- Python, Jupyter / Google Colab
- TensorFlow / Keras, PyTorch (varies by notebook)
- NumPy, Pandas, Matplotlib, Scikit-learn
- Hugging Face Transformers (for NLP notebooks)

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/SakshamSharma2006/Advance-Data-science.git
   ```
2. Open any notebook in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install dependencies as listed at the top of each notebook (commonly `tensorflow`, `torch`, `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `transformers`).
4. Run the cells sequentially.

## 📌 Notes
- Notebooks are organized by topic, not by chronological order.
- Some notebooks share overlapping content (e.g., multiple regularization or denoising autoencoder notebooks) representing iterative experiments.
